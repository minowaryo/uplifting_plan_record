# requirements.md — 要件定義

> 対象: 人間レビュー用（高レベル）
> 更新者: ビジネス側・BA
> 更新日: 2026-05-31

---

## 1. 背景・目的

現状、育成関連情報が分散しており、運用負荷と可視性不足が課題になっている。

- スキルマトリックスを従業員ごとに手作業で管理している
- 部門向けトレーニングプランと、1on1型メンタリングプランが別管理になっている
- 記録・更新・参照の導線が統一されていない

本システムの目的は、スキル評価、トレーニング計画、メンタリング計画、相互フィードバックをWeb上で一元管理し、育成活動の計画性・追跡性・透明性を向上させることである。

---

## 2. スコープ

### IN（対象）
- ログイン機能
- 認証後に自分のメンター/メンティ関連情報を確認できるマイページ
- 部門/セクション単位で管理するトレーニングプラン管理
- メンター/メンティのペア単位で管理するメンタリングプラン管理
- メンター・メンティ双方からのフィードバック登録/参照
- 従業員ごとのスキルマトリックス管理（4段階レベル）
- セクションごとに必要なスキル項目セットを設定できる（スキル項目はセクション単位でオン/オフ可能）
- スキル未入力の画面上警告表示
- 管理者/チームヘッド/セクションヘッド/一般ユーザーの権限を考慮した操作制御
- 既存Excelデータの初期移行

### OUT（対象外）
- 勤怠・給与など育成領域外の人事機能
- 外部システム連携（人事マスタ、チャット通知等）
- モバイルアプリ提供（Web画面のみ）

---

## 3. Actor（利用者）

**組織構造**: セクション ＞ チーム（チームはセクションの配下）

| Actor | 説明 | 権限レベル |
|---|---|---|
| 管理者 | システム全体設定、ユーザー管理、全データ参照/編集 | 最高権限 |
| チームヘッド | チーム単位の計画・進捗管理、配下メンバーのスキル登録・更新（主担当） | 高 |
| セクションヘッド | 配下チームを束ねたセクション全体の計画・進捗管理、スキル登録可 | 中 |
| 一般ユーザー | 自身の情報参照、フィードバック登録 | 制限あり |

補足:
- メンター/メンティはロールではなく、ユーザー間の関係として扱う
- 1ユーザーが時期や相手に応じてメンター/メンティ両方になり得る
- チームヘッドが自チームメンバーのスキル情報を入力する主担当。セクションヘッドと管理者も入力可

| F-004a | スキル項目マスタ管理 | スキル項目の追加・廃止・セクションへの割り当てを管理 | 管理者/セクションヘッド | 高 |
| F-004b | セクション別スキルセット設定 | セクションごとに評価対象とするスキル項目を設定/解除する | 管理者/セクションヘッド | 高 |
| F-005 | スキルマトリックス参照 | 個人/組織単位でスキル分布を参照 | 管理者/ヘッド | 中 |

| F-006 | トレーニングプラン管理 | セクション単位の育成計画を作成・更新・参照 | 管理者/チームヘッド/セクションヘッド | 高 |
| F-007 | メンタリングプラン管理 | メンター・メンティのペアと週次テーマを管理。毎週金曜日までに翌週分を登録する運用 | 管理者/ヘッド/メンター | 高 |

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 可用性 | 業務時間帯で安定稼働（平日運用を前提） |
| パフォーマンス | 一般画面の主要操作は3秒以内に応答（通常負荷時） |
| セキュリティ | 認証必須、権限に基づくアクセス制御、OWASP Top 10を考慮 |
| 監査性 | 主要な更新操作を追跡可能にする |
| データ保持 | 育成履歴とフィードバック履歴を継続保管 |

---

## 6. 制約・前提

- 本フェーズではWebアプリ（PCブラウザ利用）を優先する
- ロールとメンター/メンティ関係は別軸で設計する
- スキル評価レベルは固定で1〜4とする
- トレーニングプラン（組織向け）とメンタリングプラン（個別ペア向け）は別機能として実装する
- スキル項目はシステム全体で共通のマスタを持ち、セクションごとに利用するかどうかを設定する形とする
- 既存データはExcel管理のため、初期データ移行が必要（移行設計は別途）

## 7. 確定事項（2026-05-31）

| 項目 | 決定内容 |
|---|---|
| 組織構造 | セクション ＞ チーム（チームはセクションの配下） |
| フィードバック公開範囲 | メンター・メンティ当事者に加え、チームヘッド・セクションヘッド・管理者が参照可 |
| スキル登録権限 | チームヘッド（主担当）・セクションヘッド・管理者が登録可。一般ユーザーは自分のスキルを参照のみ |
| スキル項目マスタ編集権限 | セクションヘッドと管理者が追加/廃止可。セクションへの割り当てもセクションヘッド以上 |
| セクション別スキル設定 | スキル項目はシステム全体で共通マスタを持ち、セクションごとに利用する項目をオン/オフ設定する |
| メンタリングプラン締め日 | 毎週金曜日。翌週分のテーマが必ず登録済みの状態にする |
| スキル未入力の通知方式 | 画面表示による警告（未入力を都度検知して警告表示）。システム通知は画面内のみ（F-005a） |
| 既存データ移行 | あり。現在Excelで管理しているデータを初期移行する（移行設計は別フェーズで検討） |

## 8. 未確定事項（レビュー要）

- 既存Excelデータの項目定義と移行対象の精査（移行設計フェーズで別途対応）
- スキル未入力警告の表示条件（全スキル未入力のみか、一部未入力も含むか）
